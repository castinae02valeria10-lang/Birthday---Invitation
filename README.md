# 🎉 Invitación de Cumpleaños

Invitación web interactiva que hice para mi cumpleaños, como práctica de HTML, CSS y JavaScript.

## ✨ Qué tiene

- Sobre animado que se abre al tocarlo
- Carrusel de fotos deslizable
- Tarjeta con fecha, hora y lugar (con link directo a Google Maps)
- Botón de RSVP con un "No" que se escapa 😄
- Animación de corazones al confirmar asistencia
- Nombre de invitada personalizable por URL (`?nombre=Argeli`)

## 🛠️ Tecnologías

- HTML5
- CSS3 (variables, animaciones, `clip-path`)
- JavaScript (vanilla, sin librerías)

## 🔗 Ver en vivo

[Abrir invitación](https://castinae02valeria10-lang.github.io/Birthday---Invitation/)

## 📸 Personalizar

Para reemplazar las fotos, agrega tus imágenes en la carpeta `img/` y actualiza el `src` en `index.html`.
